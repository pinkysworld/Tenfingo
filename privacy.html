Welche Daten die App verarbeitetData processed by the app

Tenfingo verarbeitet Tastatureingaben während einer Übung, den Übungstext und lokale Trainingsprofile. Ein Profil enthält den eingegebenen Namen, eine zufällig erzeugte Profilkennung, Tastaturlayout, Kindermodus, Avatarfarbe und freigeschaltete Lektionen. Ein Spitzname genügt; ein Geburtsdatum oder das tatsächliche Alter werden nicht abgefragt.

Tenfingo processes keyboard input during practice, the exercise text and local training profiles. A profile contains the name you enter, a randomly generated profile identifier, keyboard layout, child-mode setting, avatar colour and unlocked lessons. A nickname is sufficient; the app does not ask for a date of birth or actual age.

Gespeicherte Übungsergebnisse enthalten eine zufällige Sitzungskennung, Zeitpunkt, Layout, gegebenenfalls Lektion, Abschlussstatus, Anschläge, Fehler, Übungsdauer sowie Fehler- und Zeitwerte je erwarteter Taste und Buchstabenpaar. Daraus berechnet die App Genauigkeit, Anschläge pro Minute, Verlauf und Übungsschwerpunkte. Sie überwacht keine Eingaben außerhalb der eigenen Übungsoberfläche.

Saved exercise results contain a random session identifier, time, layout, lesson where applicable, completion status, keystrokes, errors, duration, and error and timing statistics for each expected key and letter pair. These are used to calculate accuracy, keystrokes per minute, progress and practice priorities. The app does not monitor typing outside its own practice interface.

Eingefügte eigene Texte werden nicht als vollständiges Textdokument im Profil gespeichert. Die Statistiken enthalten jedoch Zeichen und Buchstabenpaare aus dem erwarteten Übungstext. Daraus können Textteile erkennbar sein. Füge deshalb keine Passwörter, vertraulichen Dokumente oder andere unnötige persönliche Daten als Übungstext ein.

Pasted custom text is not saved in the profile as a complete text document. Statistics do, however, include characters and letter pairs from the expected exercise text, which can reveal fragments. Do not paste passwords, confidential documents or unnecessary personal information as practice text.

Lokale Speicherung und LöschungLocal storage and deletion

Die Profile und Ergebnisse stehen in profiles.json im lokalen Anwendungsdatenordner Tenfingo, unter Windows normalerweise %LOCALAPPDATA%\Tenfingo. Bei einem paketierten Windows-Store-Programm kann Windows diesen Pfad in das lokale Paketverzeichnis umleiten. Die Datei ist eine normale JSON-Datei ohne eigene App-Verschlüsselung. Personen mit Zugriff auf das Windows-Benutzerkonto oder die Datei können sie lesen; Profile in der App bilden keine getrennten geschützten Benutzerkonten.

Profiles and results are stored in profiles.json in the local application data folder Tenfingo, normally %LOCALAPPDATA%\Tenfingo on Windows. For a packaged Windows Store app, Windows may redirect this path to the local package directory. The file is ordinary JSON without app-level encryption. Anyone with access to the Windows user account or file can read it; app profiles are not separate protected user accounts.

Daneben legt die App im selben Ordner license.txt (gemerkter Kaufstatus für den Offline-Betrieb) und language.txt (gewählte Sprache) an. Für die Fehlersuche schreibt sie ein kurzes Startprotokoll tenfingo-start.log in den temporären Windows-Ordner; es enthält technische Meldungen, Startargumente und Fehlermeldungen, und wird ab 256 KB neu begonnen. Wer alle lokalen Daten entfernen möchte, löscht den ganzen Ordner Tenfingo und diese Protokolldatei.

Next to it the app keeps license.txt (remembered purchase status for offline use) and language.txt (chosen language). For troubleshooting it writes a short start log tenfingo-start.log to the Windows temporary folder; it contains technical messages, startup arguments and error messages, and starts over once it reaches 256 KB. To remove all local data, delete the whole Tenfingo folder and this log file.

Die App hat keine automatische Löschfrist. Zum Entfernen aller Profile und Ergebnisse schließe die App und lösche profiles.json sowie alle Kopien mit den Dateimustern profiles.json.before-repair-* und profiles.json.damaged-* im tatsächlich verwendeten Anwendungsdatenverzeichnis. Solche Kopien können bei Reparatur oder Wiederherstellung entstehen. Alternativ kannst du den ganzen Ordner Tenfingo löschen. Das entfernt den lokalen Trainingsstand unwiderruflich. Separat gespeicherte Berichte und Betriebssystem-Sicherungen werden dadurch nicht entfernt.

There is no automatic deletion period. To remove all profiles and results, close the app and delete profiles.json and all copies matching profiles.json.before-repair-* and profiles.json.damaged-* in the application data directory actually in use. Such copies may be created during repair or recovery. Alternatively, delete the whole Tenfingo folder. This permanently removes local training progress. Separately saved reports and operating-system backups are not deleted by this action.

PDF-Berichte werden nur auf deinen Wunsch am ausgewählten Ort gespeichert. Sie enthalten Profilname und Fortschrittsdaten. Du entscheidest, wann du sie löschst oder weitergibst. Bei einem synchronisierten Ordner kann dessen Dienst Dateien unabhängig von Tenfingo übertragen.

PDF reports are saved only when you request them, at your chosen location. They contain the profile name and progress data. You decide when to delete or share them. If you choose a synchronised folder, its service may transfer files independently of Tenfingo.

Keine App-Telemetrie; Microsoft StoreNo app telemetry; Microsoft Store

Die App implementiert keine eigenen Netzwerkaufrufe, Werbung, Analyse-Telemetrie, Cloud-Synchronisation oder Online-Konten. Profil- und Übungsdaten werden nicht durch Tenfingo an den Entwickler gesendet. Kindermodus ändert die Darstellung, nicht den Speicherort oder den lokalen Zugriffsschutz.

The app implements no network calls of its own, advertising, analytics telemetry, cloud synchronisation or online accounts. Tenfingo does not send profile or practice data to the developer. Child mode changes presentation, not storage location or local access protection.

Lizenzprüfung und Kauf der Store-Version verwenden Microsoft-Dienste. Dabei können Verbindungs-, Konto-, Lizenz- und Transaktionsdaten gemäß der Datenschutzerklärung von Microsoft verarbeitet werden. Die App erhält den Lizenz- und Kaufstatus, keine Kreditkartennummer. Diese Erklärung sagt nichts darüber aus, welche eigenen Diagnose-, Sicherungs- oder Synchronisationsfunktionen Windows und andere Programme nutzen.

Store-version licence checks and purchases use Microsoft services. Connection, account, licence and transaction data may be processed under the Microsoft privacy statement. The app receives licence and purchase status, not credit card numbers. This statement does not describe independent diagnostic, backup or synchronisation functions of Windows or other software.
